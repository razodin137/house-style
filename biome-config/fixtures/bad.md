# House style


Biome formats Markdown and YAML.    JavaScript, CSS, and HTML stay with their own tools.

## Rules

*   Two-space indentation
*   Double quotes in code
*   No trailing commas

| Tool | Scope |
|---|---|
| Biome | Markdown, YAML |
| ESLint | JavaScript |

> Block quotes keep their marker.

```json
{ "name": "house-style" }
```
